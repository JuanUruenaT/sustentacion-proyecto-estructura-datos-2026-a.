Listas Enlazadas Dobles y Circulares

Las listas dobles y circulares permiten recorrer información en diferentes direcciones, facilitando procesos dinámicos y sistemas que requieren navegación continua entre datos conectados.

1. Documentación

Definición

Las listas enlazadas dobles son estructuras dinámicas compuestas por nodos que contienen tres partes fundamentales: un dato, una referencia al nodo siguiente y otra referencia al nodo anterior. Gracias a esta doble conexión, es posible recorrer la estructura tanto hacia adelante como hacia atrás, algo que no ocurre en las listas simples. Esta característica las hace muy útiles en aplicaciones donde el usuario necesita desplazarse entre elementos en diferentes direcciones. Por otra parte, las listas circulares son estructuras donde el último nodo vuelve a conectarse con el primero, formando un ciclo continuo. Dependiendo de la implementación, las listas circulares pueden ser simples o dobles. Estas estructuras son utilizadas en sistemas que requieren recorridos repetitivos y continuos sin necesidad de reiniciar el proceso manualmente.

Utilidad

Las listas dobles son ampliamente utilizadas en reproductores de música, navegadores web y sistemas de historial donde es necesario avanzar o retroceder entre elementos. Por ejemplo, cuando una persona escucha canciones en una aplicación musical, puede pasar a la siguiente pista o regresar a la anterior gracias al uso de listas doblemente enlazadas. Las listas circulares, en cambio, son comunes en sistemas de turnos automáticos, videojuegos, simulaciones y sistemas operativos donde los procesos se ejecutan de forma repetitiva y continua.

Características

  • Permiten recorrer datos hacia adelante y atrás.
  • Los nodos poseen múltiples referencias.
  • Facilitan inserciones y eliminaciones dinámicas.
  • Las listas circulares generan recorridos continuos.
  • Son muy utilizadas en sistemas interactivos.
  • No requieren tamaño fijo de memoria.

Representación

null ← [Nodo1] ⇄ [Nodo2] ⇄ [Nodo3] → null
    
[Nodo1] → [Nodo2] → [Nodo3]
    ↑_____________________↓

Casos de uso

Un ejemplo moderno aparece en las plataformas de streaming de música donde las canciones se encuentran conectadas entre sí para avanzar o retroceder fácilmente dentro de una playlist. Otro caso ocurre en los sistemas de control de tráfico aéreo, donde los aviones en espera pueden organizarse mediante estructuras circulares para administrar turnos de aterrizaje de manera continua.

2. Ejemplos Solucionados

Ejemplo 1

Una aplicación astronómica necesita recorrer planetas detectados tanto hacia adelante como hacia atrás. 

class Planeta {

    String nombre;
    Planeta siguiente;
    Planeta anterior;

    public Planeta(String nombre){

        this.nombre = nombre;
    }
}

public class SistemaPlanetario {

    public static void main(String[] args) {

        Planeta p1 = new Planeta("Mercurio-X");
        Planeta p2 = new Planeta("Ares-9");
        Planeta p3 = new Planeta("Titan-Blue");

        p1.siguiente = p2;
        p2.anterior = p1;

        p2.siguiente = p3;
        p3.anterior = p2;

        System.out.println("Recorrido hacia adelante:");

        System.out.println(p1.nombre);
        System.out.println(p1.siguiente.nombre);
        System.out.println(p2.siguiente.nombre);

        System.out.println("Recorrido hacia atrás:");

        System.out.println(p3.nombre);
        System.out.println(p3.anterior.nombre);
        System.out.println(p2.anterior.nombre);
    }
}

Explicación paso a paso:

  • Cada nodo almacena un planeta.
  • Los nodos se conectan en ambas direcciones.
  • Es posible recorrer la estructura hacia adelante.
  • También puede recorrerse hacia atrás.
  • La información se muestra dinámicamente.

Ejemplo 2

Un sistema automático de vigilancia necesita recorrer cámaras de seguridad continuamente mediante una lista circular. 

class Camara {

    String zona;
    Camara siguiente;

    public Camara(String zona){

        this.zona = zona;
    }
}

public class Vigilancia {

    public static void main(String[] args) {

        Camara c1 = new Camara("Zona Norte");
        Camara c2 = new Camara("Zona Central");
        Camara c3 = new Camara("Zona Sur");

        c1.siguiente = c2;
        c2.siguiente = c3;
        c3.siguiente = c1;

        Camara actual = c1;

        for(int i = 0; i < 6; i++){

            System.out.println(actual.zona);

            actual = actual.siguiente;
        }
    }
}
