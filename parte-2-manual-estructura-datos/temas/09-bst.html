Árboles Binarios de Búsqueda — BST

Los árboles binarios de búsqueda permiten almacenar información ordenadamente para realizar búsquedas rápidas y eficientes dentro de grandes volúmenes de datos.

1. Documentación

Definición

Los árboles binarios de búsqueda, conocidos como BST (Binary Search Tree), son una variación especializada de los árboles binarios tradicionales. Su principal característica es que mantienen los datos organizados siguiendo reglas específicas de ordenamiento. En un BST, todos los valores menores que el nodo principal se almacenan en el subárbol izquierdo, mientras que los valores mayores se almacenan en el subárbol derecho. Gracias a esta organización, las búsquedas pueden realizarse de manera extremadamente rápida, evitando recorrer toda la estructura completa. Esto convierte a los BST en estructuras muy eficientes para aplicaciones donde constantemente se realizan consultas, inserciones y eliminaciones. Los BST son ampliamente utilizados en bases de datos, motores de búsqueda, sistemas financieros y plataformas de inteligencia artificial.

Utilidad

Los árboles BST permiten administrar grandes cantidades de información ordenada de forma automática. Por ejemplo, en un sistema bancario donde millones de transacciones deben localizarse rápidamente, los BST facilitan búsquedas eficientes. También son utilizados en videojuegos para organizar puntuaciones, en plataformas de comercio electrónico para clasificar productos y en sistemas médicos donde se administran historiales clínicos. Su gran ventaja consiste en reducir significativamente el tiempo necesario para encontrar información específica dentro de una estructura compleja.

Características

  • Los valores menores van a la izquierda.
  • Los valores mayores van a la derecha.
  • Facilitan búsquedas rápidas.
  • Permiten inserciones ordenadas.
  • Son estructuras jerárquicas.
  • Optimización eficiente del procesamiento.

Casos de uso

Un caso moderno ocurre en plataformas de streaming musical donde las canciones pueden organizarse mediante árboles BST para facilitar búsquedas rápidas según nombre, artista o popularidad. Otro ejemplo aparece en sistemas de navegación GPS donde múltiples rutas deben organizarse eficientemente para calcular trayectos óptimos.

2. Operaciones Principales

Inserción

Consiste en agregar nuevos nodos respetando las reglas de ordenamiento del árbol binario de búsqueda.

Búsqueda

Permite localizar rápidamente un dato recorriendo únicamente una parte específica del árbol.

Eliminación

Elimina nodos reorganizando automáticamente la estructura.

Recorridos

Los árboles BST pueden recorrerse mediante diferentes métodos como:

  • Preorden
  • Inorden
  • Postorden

3. Ejemplos Solucionados

Ejemplo 1

Una estación espacial necesita almacenar niveles de radiación organizados automáticamente. 

class Nodo {

    int dato;
    Nodo izquierdo;
    Nodo derecho;

    public Nodo(int dato){

        this.dato = dato;
    }
}

public class BST {

    Nodo raiz;

    public Nodo insertar(Nodo nodo, int dato){

        if(nodo == null){

            return new Nodo(dato);
        }

        if(dato < nodo.dato){

            nodo.izquierdo = insertar(nodo.izquierdo, dato);

        } else {

            nodo.derecho = insertar(nodo.derecho, dato);
        }

        return nodo;
    }

    public void inorden(Nodo nodo){

        if(nodo != null){

            inorden(nodo.izquierdo);

            System.out.println(nodo.dato);

            inorden(nodo.derecho);
        }
    }

    public static void main(String[] args) {

        BST arbol = new BST();

        arbol.raiz = arbol.insertar(arbol.raiz, 60);
        arbol.raiz = arbol.insertar(arbol.raiz, 30);
        arbol.raiz = arbol.insertar(arbol.raiz, 90);
        arbol.raiz = arbol.insertar(arbol.raiz, 20);

        arbol.inorden(arbol.raiz);
    }
}

Explicación paso a paso:

  • Se crea la estructura Nodo.
  • Los datos se insertan automáticamente.
  • Los valores menores van a la izquierda.
  • Los mayores se ubican a la derecha.
  • El recorrido inorden muestra datos ordenados.

Ejemplo 2

Un laboratorio oceánico necesita buscar rápidamente profundidades registradas. 

class Nodo {

    int profundidad;
    Nodo izquierdo;
    Nodo derecho;

    public Nodo(int profundidad){

        this.profundidad = profundidad;
    }
}

public class OceanoBST {

    public static boolean buscar(Nodo nodo, int valor){

        if(nodo == null){

            return false;
        }

        if(nodo.profundidad == valor){

            return true;
        }

        if(valor < nodo.profundidad){

            return buscar(nodo.izquierdo, valor);

        } else {

            return buscar(nodo.derecho, valor);
        }
    }

    public static void main(String[] args) {

        Nodo raiz = new Nodo(500);

        raiz.izquierdo = new Nodo(300);
        raiz.derecho = new Nodo(800);

        System.out.println(buscar(raiz, 800));
    }
}
