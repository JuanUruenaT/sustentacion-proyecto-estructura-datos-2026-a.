Colas — Queue y Variantes

Las colas son estructuras de datos que organizan elementos siguiendo el principio FIFO, donde el primer dato en entrar es el primero en salir.

1. Documentación

Definición

Las colas, conocidas también como Queue, son estructuras de datos lineales que funcionan bajo el principio FIFO (First In, First Out), lo que significa que el primer elemento que ingresa será el primero en salir. Su funcionamiento puede compararse con una fila de personas esperando atención en un banco o en un aeropuerto. La primera persona que llega es la primera en ser atendida, mientras que las demás esperan su turno detrás. En programación, las colas permiten administrar procesos organizados en orden cronológico, garantizando que los datos sean procesados respetando el orden de llegada. Las operaciones principales de una cola son:

  • Enqueue: agrega un elemento al final de la cola.
  • Dequeue: elimina el primer elemento de la cola.
  • Peek: permite observar el primer elemento.

Utilidad

Las colas son ampliamente utilizadas en sistemas operativos, servidores, plataformas bancarias y redes de comunicación. Por ejemplo, las impresoras manejan documentos utilizando colas para procesar cada archivo en orden. También aparecen en videojuegos multijugador donde los jugadores esperan turnos de conexión, en hospitales donde se organizan pacientes y en sistemas de inteligencia artificial donde múltiples tareas deben ejecutarse ordenadamente. Existen diferentes variantes de colas como las colas circulares, colas dobles y colas de prioridad, cada una diseñada para resolver necesidades específicas.

Características

  • Funcionan bajo el principio FIFO.
  • Los elementos ingresan por el final.
  • Los elementos salen por el frente.
  • Permiten administrar procesos ordenados.
  • Son muy utilizadas en sistemas multitarea.
  • Existen múltiples variantes especializadas.

Casos de uso

Un caso muy común ocurre en los sistemas aeroportuarios donde los aviones esperan autorización para despegar en orden de llegada. Otro ejemplo aparece en plataformas de videojuegos online donde los jugadores son colocados en colas automáticas antes de ingresar a partidas multijugador.

2. Ejemplos Solucionados

Ejemplo 1

Un laboratorio automatizado necesita procesar muestras químicas en el mismo orden en que llegan al sistema. 

import java.util.LinkedList;
import java.util.Queue;

public class Laboratorio {

    public static void main(String[] args) {

        Queue muestras = new LinkedList<>();

        muestras.add("Muestra-A1");
        muestras.add("Muestra-B9");
        muestras.add("Muestra-C5");

        System.out.println("Primera muestra:");

        System.out.println(muestras.peek());

        muestras.remove();

        System.out.println("Nueva muestra al frente:");

        System.out.println(muestras.peek());
    }
}

Explicación paso a paso:

  • Se crea una cola utilizando Queue.
  • Las muestras ingresan mediante add().
  • peek() permite observar el primer dato.
  • remove() elimina el primer elemento.
  • La cola reorganiza automáticamente el orden.

Ejemplo 2

Un sistema de control marítimo necesita administrar barcos esperando permiso para ingresar al puerto. 

import java.util.LinkedList;
import java.util.Queue;

public class Puerto {

    public static void main(String[] args) {

        Queue barcos = new LinkedList<>();

        barcos.add("Barco Atlas");
        barcos.add("Barco Neptune");
        barcos.add("Barco Horizon");

        while(!barcos.isEmpty()){

            System.out.println("Ingresando:");

            System.out.println(barcos.remove());
        }
    }
}

3. Variantes de Colas

Cola Circular

La cola circular conecta el último espacio nuevamente con el primero, optimizando el uso de memoria y permitiendo reutilizar posiciones vacías.

Cola Doble

Permite insertar y eliminar elementos tanto al inicio como al final de la estructura.

Cola de Prioridad

Los elementos se organizan según un nivel de prioridad y no únicamente por orden de llegada.
