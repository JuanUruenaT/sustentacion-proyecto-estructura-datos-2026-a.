Listas Enlazadas Simples

Las listas enlazadas simples permiten almacenar información de manera dinámica mediante nodos conectados entre sí, facilitando la inserción y eliminación de datos sin necesidad de reorganizar toda la estructura.

1. Documentación

Definición

Las listas enlazadas simples son estructuras de datos dinámicas compuestas por nodos. Cada nodo contiene dos partes fundamentales: un dato y una referencia que apunta hacia el siguiente nodo de la lista. A diferencia de los arrays, las listas enlazadas no almacenan los elementos en posiciones consecutivas de memoria, sino que cada nodo puede encontrarse en diferentes ubicaciones y conectarse mediante referencias. Esta característica permite que la estructura pueda crecer o disminuir durante la ejecución del programa sin necesidad de reservar memoria fija desde el inicio. Por esta razón, las listas enlazadas son ampliamente utilizadas en sistemas donde la cantidad de información cambia constantemente.

Utilidad

Las listas enlazadas son muy útiles cuando se requiere insertar o eliminar datos frecuentemente. Por ejemplo, en aplicaciones hospitalarias donde ingresan pacientes constantemente, en sistemas de reproducción musical o en plataformas que manejan colas dinámicas de usuarios. También son utilizadas en sistemas operativos, videojuegos y aplicaciones de inteligencia artificial debido a la flexibilidad que ofrecen para administrar grandes cantidades de datos dinámicos.

Características

  • Son estructuras dinámicas.
  • No requieren tamaño fijo.
  • Cada nodo apunta al siguiente.
  • Permiten inserciones rápidas.
  • Facilitan la eliminación de elementos.
  • Utilizan memoria únicamente cuando es necesaria.

Representación

[Nodo1|•] → [Nodo2|•] → [Nodo3|•] → [null]

Casos de uso

Un ejemplo muy común ocurre en aplicaciones de navegación web. Cada página visitada puede almacenarse como un nodo enlazado al siguiente historial, permitiendo avanzar o retroceder entre páginas consultadas. Otro caso importante aparece en videojuegos multijugador donde continuamente ingresan y salen jugadores conectados al servidor.

2. Ejemplos Solucionados

Ejemplo 1

Una aplicación científica necesita registrar satélites detectados durante una exploración espacial. 

class Nodo {

    String satelite;
    Nodo siguiente;

    public Nodo(String satelite){

        this.satelite = satelite;
        this.siguiente = null;
    }
}

public class ListaSatelites {

    public static void main(String[] args) {

        Nodo n1 = new Nodo("Hubble-X");
        Nodo n2 = new Nodo("Nova-21");
        Nodo n3 = new Nodo("Explorer-9");

        n1.siguiente = n2;
        n2.siguiente = n3;

        Nodo actual = n1;

        while(actual != null){

            System.out.println(actual.satelite);

            actual = actual.siguiente;
        }
    }
}

Explicación paso a paso:

  • Se crea la clase Nodo.
  • Cada nodo almacena un nombre y una referencia.
  • Los nodos se conectan entre sí.
  • El ciclo recorre toda la lista.
  • Los satélites se muestran en pantalla.

Ejemplo 2

Un laboratorio registra muestras biológicas analizadas durante una investigación. 

class Muestra {

    String codigo;
    Muestra siguiente;

    public Muestra(String codigo){

        this.codigo = codigo;
    }
}

public class Laboratorio {

    public static void main(String[] args) {

        Muestra m1 = new Muestra("BIO-900");
        Muestra m2 = new Muestra("BIO-901");

        m1.siguiente = m2;

        System.out.println(m1.codigo);
        System.out.println(m1.siguiente.codigo);
    }
}

Pista: Cada nodo debe apuntar al siguiente nodo.
