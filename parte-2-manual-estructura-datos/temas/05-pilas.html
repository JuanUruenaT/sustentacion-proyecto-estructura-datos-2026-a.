Pilas — Stack

Las pilas son estructuras de datos lineales que organizan los elementos siguiendo el principio LIFO, donde el último dato en entrar es el primero en salir.

1. Documentación

Definición

Una pila, conocida también como Stack, es una estructura de datos lineal que funciona bajo el principio LIFO (Last In, First Out), lo que significa que el último elemento agregado será el primero en eliminarse. Su funcionamiento puede compararse con una torre de platos. Cuando se agrega un nuevo plato, este queda ubicado en la parte superior, y cuando se necesita retirar uno, siempre se toma primero el que está arriba. Las pilas son ampliamente utilizadas en programación debido a que permiten controlar procesos temporales, almacenar información de ejecución y resolver problemas relacionados con recursividad, historial y navegación. Dentro de las pilas existen dos operaciones fundamentales:

  • Push: agrega un elemento a la pila.
  • Pop: elimina el elemento superior.

Utilidad

Las pilas son utilizadas en múltiples sistemas modernos. Por ejemplo, los navegadores web utilizan pilas para almacenar el historial de páginas visitadas, permitiendo regresar a páginas anteriores. También son utilizadas en editores de texto para implementar funciones de deshacer y rehacer cambios, en compiladores para administrar llamadas de funciones y en videojuegos para controlar acciones temporales del jugador. Otra aplicación importante aparece en sistemas robóticos y de inteligencia artificial donde se requiere almacenar decisiones temporales antes de ejecutar procesos complejos.

Características

  • Funcionan bajo el principio LIFO.
  • Las inserciones y eliminaciones ocurren en la parte superior.
  • Permiten administrar procesos temporales.
  • Son estructuras lineales.
  • Facilitan algoritmos recursivos.
  • Son ampliamente utilizadas en sistemas operativos y compiladores.

Casos de uso

Un ejemplo moderno ocurre en los sistemas de navegación de drones autónomos. Cada movimiento realizado por el dron puede almacenarse en una pila para permitir regresar automáticamente al punto de origen en caso de emergencia. Otro caso importante aparece en aplicaciones de diseño gráfico donde las acciones del usuario se almacenan temporalmente para permitir la función de deshacer cambios.

2. Ejemplos Solucionados

Ejemplo 1

Un centro de investigación espacial necesita almacenar reportes temporales de sensores utilizando una pila. 

import java.util.Stack;

public class ReportesEspaciales {

    public static void main(String[] args) {

        Stack reportes = new Stack<>();

        reportes.push("Temperatura detectada");
        reportes.push("Movimiento sísmico");
        reportes.push("Cambio atmosférico");

        System.out.println("Último reporte almacenado:");

        System.out.println(reportes.peek());

        reportes.pop();

        System.out.println("Reporte eliminado.");

        System.out.println("Nuevo elemento superior:");

        System.out.println(reportes.peek());
    }
}

Explicación paso a paso:

  • Se crea una pila llamada reportes.
  • Los datos se agregan mediante push().
  • peek() permite observar el elemento superior.
  • pop() elimina el último elemento agregado.
  • La pila se reorganiza automáticamente.

Ejemplo 2

Un sistema de realidad virtual necesita almacenar movimientos realizados por un usuario para permitir retroceder acciones. 

import java.util.Stack;

public class RealidadVirtual {

    public static void main(String[] args) {

        Stack movimientos = new Stack<>();

        movimientos.push("Avanzar");
        movimientos.push("Girar derecha");
        movimientos.push("Subir escalera");

        while(!movimientos.isEmpty()){

            System.out.println("Deshaciendo:");

            System.out.println(movimientos.pop());
        }
    }
}
