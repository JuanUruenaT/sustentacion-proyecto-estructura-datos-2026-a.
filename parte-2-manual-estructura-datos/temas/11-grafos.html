Grafos: Conceptos y Presentación

Los grafos son estructuras de datos utilizadas para representar conexiones, relaciones y rutas entre diferentes elementos dentro de sistemas complejos.

1. Documentación

Definición

Los grafos son estructuras de datos no lineales formadas por vértices y aristas. Los vértices representan elementos o nodos, mientras que las aristas representan conexiones o relaciones entre dichos nodos. Esta estructura es ampliamente utilizada para modelar problemas del mundo real donde existen conexiones entre diferentes entidades. Por ejemplo, redes sociales, sistemas GPS, rutas aéreas, redes eléctricas y conexiones de internet pueden representarse mediante grafos. Los grafos pueden ser dirigidos o no dirigidos. En los grafos dirigidos, las conexiones poseen una dirección específica, mientras que en los no dirigidos la conexión funciona en ambos sentidos. También existen grafos ponderados, donde las conexiones poseen valores asociados como distancia, costo o tiempo.

Utilidad

Los grafos son fundamentales dentro de múltiples áreas tecnológicas. Por ejemplo, las aplicaciones de navegación GPS utilizan grafos para calcular rutas más rápidas entre ciudades o ubicaciones. Las redes sociales también funcionan mediante grafos, donde cada usuario representa un nodo y las amistades representan conexiones. Además, aparecen en inteligencia artificial, robótica, telecomunicaciones, videojuegos y sistemas de logística internacional donde se requiere analizar conexiones complejas entre múltiples elementos.

Características

  • Representan relaciones entre elementos.
  • Utilizan vértices y aristas.
  • Pueden ser dirigidos o no dirigidos.
  • Permiten analizar rutas y conexiones.
  • Son utilizados en inteligencia artificial y redes.
  • Facilitan cálculos de caminos mínimos.

Representación

Casos de uso

Un ejemplo moderno ocurre en aplicaciones de transporte como Uber o Google Maps, donde las calles son representadas mediante grafos para calcular trayectos eficientes. Otro caso importante aparece en plataformas de redes sociales donde millones de usuarios se conectan mediante relaciones representadas matemáticamente con grafos.

2. Tipos de Grafos

Grafos Dirigidos

Las conexiones poseen dirección específica. 

A → B → C

Grafos No Dirigidos

Las conexiones funcionan en ambos sentidos. 

A ----- B

Grafos Ponderados

Cada conexión posee un valor numérico asociado. 

A --5-- B

3. Ejemplos Solucionados

Ejemplo 1

Un sistema de transporte marítimo necesita representar rutas entre puertos internacionales. 

import java.util.*;

public class Puertos {

    public static void main(String[] args) {

        Map> grafo = new HashMap<>();

        grafo.put("Puerto Norte",
        Arrays.asList("Puerto Central", "Puerto Sur"));

        grafo.put("Puerto Central",
        Arrays.asList("Puerto Norte", "Puerto Este"));

        grafo.put("Puerto Sur",
        Arrays.asList("Puerto Norte"));

        for(String puerto : grafo.keySet()){

            System.out.println(puerto + " conecta con:");

            System.out.println(grafo.get(puerto));
        }
    }
}

Explicación paso a paso:

  • Se crea un grafo utilizando HashMap.
  • Cada puerto representa un nodo.
  • Las listas almacenan conexiones.
  • El sistema recorre todos los nodos.
  • Las rutas se muestran en pantalla.

Ejemplo 2

Una red espacial necesita representar conexiones entre satélites. 

class Grafo {

    int matriz[][] = new int[4][4];

    public void conectar(int origen, int destino){

        matriz[origen][destino] = 1;
    }

    public void mostrar(){

        for(int i = 0; i < matriz.length; i++){

            for(int j = 0; j < matriz.length; j++){

                System.out.print(matriz[i][j] + " ");
            }

            System.out.println();
        }
    }

    public static void main(String[] args) {

        Grafo g = new Grafo();

        g.conectar(0,1);
        g.conectar(1,2);
        g.conectar(2,3);

        g.mostrar();
    }
}

4. Recorridos en Grafos

DFS — Depth First Search

Explora profundamente cada camino antes de retroceder.

BFS — Breadth First Search

Recorre primero todos los nodos cercanos antes de avanzar.
