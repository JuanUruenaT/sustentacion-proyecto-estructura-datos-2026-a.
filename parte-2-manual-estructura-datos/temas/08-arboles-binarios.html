Árboles Binarios

Los árboles binarios permiten organizar información jerárquicamente mediante nodos conectados, facilitando búsquedas, recorridos y administración eficiente de datos complejos.

1. Documentación

Definición

Los árboles binarios son estructuras de datos jerárquicas compuestas por nodos conectados entre sí. Cada nodo puede contener información y tener máximo dos nodos hijos conocidos como hijo izquierdo e hijo derecho. El primer nodo del árbol recibe el nombre de raíz y representa el punto principal desde donde se conectan todos los demás nodos. A partir de allí, la estructura se expande formando diferentes niveles. Los árboles binarios son muy importantes dentro de la programación debido a que permiten representar información organizada jerárquicamente, facilitando búsquedas rápidas y recorridos eficientes. Este tipo de estructuras son ampliamente utilizadas en inteligencia artificial, bases de datos, videojuegos, compiladores y sistemas de navegación.

Utilidad

Los árboles binarios son utilizados cuando se necesita organizar información en forma jerárquica. Por ejemplo, en sistemas genealógicos donde cada persona puede relacionarse con diferentes descendientes o en plataformas educativas donde existen categorías y subcategorías organizadas. También aparecen en sistemas de archivos de computadores, donde las carpetas contienen subcarpetas y documentos conectados jerárquicamente. En videojuegos modernos, los árboles binarios son utilizados para controlar decisiones automáticas de personajes y comportamientos de inteligencia artificial.

Características

  • Son estructuras jerárquicas.
  • Cada nodo puede tener máximo dos hijos.
  • Poseen un nodo principal llamado raíz.
  • Facilitan búsquedas eficientes.
  • Permiten recorridos organizados.
  • Son utilizadas en múltiples sistemas tecnológicos.

Casos de uso

Un caso muy común ocurre en los sistemas de almacenamiento en la nube. Las carpetas y archivos se organizan jerárquicamente utilizando estructuras similares a árboles. Otro ejemplo aparece en videojuegos de estrategia donde las decisiones automáticas de los personajes se calculan mediante árboles de decisiones.

2. Partes de un Árbol Binario

Raíz

Es el nodo principal desde donde inicia toda la estructura del árbol.

Nodos Hijos

Son los nodos conectados debajo de otro nodo principal.

Hojas

Son nodos que no poseen hijos.

Subárbol

Corresponde a una sección interna del árbol principal.

3. Ejemplos Solucionados

Ejemplo 1

Una estación meteorológica necesita organizar sensores climáticos mediante un árbol binario. 

class Nodo {

    int dato;
    Nodo izquierdo;
    Nodo derecho;

    public Nodo(int dato){

        this.dato = dato;
    }
}

public class Sensores {

    public static void main(String[] args) {

        Nodo raiz = new Nodo(50);

        raiz.izquierdo = new Nodo(30);
        raiz.derecho = new Nodo(80);

        raiz.izquierdo.izquierdo = new Nodo(10);
        raiz.izquierdo.derecho = new Nodo(40);

        System.out.println("Nodo raíz:");

        System.out.println(raiz.dato);

        System.out.println("Hijo izquierdo:");

        System.out.println(raiz.izquierdo.dato);

        System.out.println("Hijo derecho:");

        System.out.println(raiz.derecho.dato);
    }
}

Explicación paso a paso:

  • Se crea la clase Nodo.
  • Cada nodo posee hijos izquierdo y derecho.
  • La raíz inicia el árbol.
  • Los demás nodos se conectan jerárquicamente.
  • La información se muestra en pantalla.

Ejemplo 2

Un sistema submarino necesita recorrer nodos de exploración. 

class Nodo {

    String zona;
    Nodo izquierdo;
    Nodo derecho;

    public Nodo(String zona){

        this.zona = zona;
    }
}

public class Oceano {

    public static void recorrer(Nodo nodo){

        if(nodo != null){

            System.out.println(nodo.zona);

            recorrer(nodo.izquierdo);

            recorrer(nodo.derecho);
        }
    }

    public static void main(String[] args) {

        Nodo raiz = new Nodo("Zona Central");

        raiz.izquierdo = new Nodo("Zona Norte");
        raiz.derecho = new Nodo("Zona Sur");

        recorrer(raiz);
    }
}
