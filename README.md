## Descripción general del proyecto

Este repositorio contiene el desarrollo completo del proyecto académico realizado para la asignatura de Desarrollo Web y Estructuras de Datos.

El proyecto está dividido en dos subproyectos completamente independientes:

* **Parte 1:** Sistema web de gestión de turnos para farmacia.

Cada parte fue desarrollada utilizando tecnologías frontend y backend modernas, aplicando conceptos de arquitectura web, persistencia de datos, APIs REST y organización modular de proyectos.

# Parte 1 — Sistema Web de Gestión de Turnos

La Parte 1 corresponde al desarrollo de una aplicación web para la administración de turnos en una farmacia.

El sistema permite:

* Registrar personas.
* Crear categorías de atención.
* Generar turnos.
* Administrar estados de turnos.
* Gestionar turnos desde un panel administrador.

Tecnologías utilizadas:

* Spring Boot
* Spring Data JPA
* H2 Database
* HTML
* CSS
* JavaScript
* Axios

La aplicación funciona bajo una arquitectura frontend/backend utilizando APIs REST para la comunicación entre el cliente y el servidor.

---

# Parte 2 — Manual Web de Estructuras de Datos

La Parte 2 corresponde al desarrollo de un manual web interactivo sobre estructuras de datos.

El manual fue construido como una página web estática que contiene documentación, ejemplos, retos y clips explicativos sobre los temas vistos durante el semestre.

Temas desarrollados:

* Arrays
* Listas enlazadas
* Pilas
* Colas
* Tablas Hash
* Árboles binarios
* AVL
* BST
* Grafos
* Complejidad algorítmica

Tecnologías utilizadas:

* HTML
* CSS
* JavaScript

El objetivo principal del manual es servir como herramienta de apoyo académico y consulta sobre estructuras de datos.
