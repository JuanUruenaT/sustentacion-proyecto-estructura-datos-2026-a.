Árboles Balanceados — AVL

Los árboles AVL son estructuras de datos avanzadas que mantienen automáticamente el equilibrio del árbol para optimizar búsquedas, inserciones y eliminaciones de información.

1. Documentación

Definición

Los árboles AVL son una variación especializada de los árboles binarios de búsqueda (BST). Su principal característica consiste en mantener automáticamente el equilibrio de la estructura para evitar que el árbol se vuelva demasiado desordenado o inclinado hacia un solo lado. El nombre AVL proviene de los apellidos de sus creadores: Adelson-Velsky y Landis, quienes desarrollaron este modelo con el objetivo de optimizar las búsquedas dentro de árboles binarios. Un árbol AVL controla constantemente la diferencia de altura entre sus subárboles izquierdo y derecho. Cuando la diferencia supera ciertos límites, el sistema realiza rotaciones automáticas para reorganizar los nodos y mantener el equilibrio. Gracias a esto, las operaciones de búsqueda, inserción y eliminación continúan siendo rápidas incluso cuando el árbol almacena grandes cantidades de información.

Utilidad

Los árboles AVL son utilizados en sistemas donde se realizan búsquedas constantes y donde el rendimiento debe mantenerse estable. Por ejemplo, en plataformas bancarias donde millones de operaciones deben localizarse rápidamente, los árboles AVL ayudan a evitar retrasos y optimizan el tiempo de respuesta. También aparecen en motores de búsqueda, sistemas médicos, videojuegos, inteligencia artificial y aplicaciones científicas que manejan enormes volúmenes de datos dinámicos.

Características

  • Mantienen equilibrio automático.
  • Optimizan búsquedas complejas.
  • Utilizan rotaciones automáticas.
  • Son una evolución de los BST.
  • Reducen tiempos de procesamiento.
  • Funcionan eficientemente con grandes cantidades de datos.

2. Rotaciones en AVL

Rotación Simple a la Derecha

Se utiliza cuando el árbol se inclina demasiado hacia la izquierda.

Rotación Simple a la Izquierda

Se aplica cuando el árbol se inclina excesivamente hacia la derecha.

Rotación Doble

Combina dos rotaciones para corregir desequilibrios más complejos.

Factor de Balance

Representa la diferencia de altura entre los subárboles izquierdo y derecho.

3. Ejemplos Solucionados

Ejemplo 1

Un laboratorio espacial necesita almacenar mediciones gravitacionales manteniendo el árbol balanceado. 

class Nodo {

    int dato;
    int altura;

    Nodo izquierdo;
    Nodo derecho;

    public Nodo(int dato){

        this.dato = dato;
        altura = 1;
    }
}

public class AVL {

    Nodo raiz;

    int altura(Nodo nodo){

        if(nodo == null){

            return 0;
        }

        return nodo.altura;
    }

    int balance(Nodo nodo){

        if(nodo == null){

            return 0;
        }

        return altura(nodo.izquierdo) - altura(nodo.derecho);
    }

    Nodo rotarDerecha(Nodo y){

        Nodo x = y.izquierdo;

        Nodo t2 = x.derecho;

        x.derecho = y;

        y.izquierdo = t2;

        y.altura = Math.max(
        altura(y.izquierdo),
        altura(y.derecho)) + 1;

        x.altura = Math.max(
        altura(x.izquierdo),
        altura(x.derecho)) + 1;

        return x;
    }

    public static void main(String[] args) {

        System.out.println("Árbol AVL inicializado");
    }
}

Explicación paso a paso:

  • Se crea la estructura Nodo.
  • Cada nodo almacena altura.
  • El sistema calcula el balance del árbol.
  • Las rotaciones corrigen desequilibrios.
  • El árbol mantiene búsquedas eficientes.

Ejemplo 2

Un sistema oceánico necesita detectar cuándo un árbol se encuentra desbalanceado. 

class Nodo {

    int profundidad;

    Nodo izquierdo;
    Nodo derecho;

    public Nodo(int profundidad){

        this.profundidad = profundidad;
    }
}

public class Balanceo {

    public static int altura(Nodo nodo){

        if(nodo == null){

            return 0;
        }

        int izquierda = altura(nodo.izquierdo);

        int derecha = altura(nodo.derecho);

        return Math.max(izquierda, derecha) + 1;
    }

    public static void main(String[] args) {

        Nodo raiz = new Nodo(100);

        raiz.izquierdo = new Nodo(50);

        raiz.izquierdo.izquierdo = new Nodo(25);

        int diferencia =
        altura(raiz.izquierdo) -
        altura(raiz.derecho);

        System.out.println("Factor de balance:");

        System.out.println(diferencia);
    }
}

4. Ventajas y Desventajas

Ventajas

  • Búsquedas rápidas.
  • Balance automático.
  • Buen rendimiento constante.
  • Eficiencia con grandes cantidades de datos.

Desventajas

  • Implementación más compleja.
  • Las rotaciones consumen procesamiento adicional.
  • Mayor dificultad de mantenimiento.
