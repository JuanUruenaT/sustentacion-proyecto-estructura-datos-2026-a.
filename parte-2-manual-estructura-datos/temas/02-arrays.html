Arrays

1. Documentación

Definición

Los arrays son estructuras de datos que permiten almacenar varios elementos del mismo tipo dentro de una sola variable. Cada elemento ocupa una posición específica llamada índice, la cual empieza normalmente desde 0. Son una de las estructuras más básicas y más utilizadas en programación porque permiten organizar información de forma ordenada y acceder rápidamente a cualquier elemento.

Utilidad

Se usan cuando necesitamos almacenar varios datos relacionados, como:

  • Notas de estudiantes
  • Lista de productos
  • Edades
  • Temperaturas registradas
  • Resultados de evaluaciones

    • Características

    • Guardan elementos del mismo tipo
    • Tienen tamaño definido
    • Se accede por índice
    • Son eficientes para acceso rápido
    • No permiten insertar o eliminar elementos fácilmente
