# Comandos para iniciar el proyecto

# Abrir el backend

Entrar a la carpeta:
cd parte-1-mi-primera-web/backend-springboot

---

# Iniciar el sistema

Ejecutar nuevamente:
./mvnw spring-boot:run

---

# Detener el servidor

En la terminal presionar:
CTRL + C

---

# Abrir el frontend

Abrir el archivo:
frontend-html-axios/index.html
